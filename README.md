# zero

A small Lean corpus and the gate that checks it.

**Deliberately contains no numbers.** Every count, exit status and timing lives
in `STATE.md`, which is generated by `bin/report.sh` and cannot be edited by
hand without failing `bin/verify.sh`. Prose drifts from the artifact; that has
happened here repeatedly and is designed out rather than warned about.

## Check it yourself

    curl https://elan.lean-lang.org/elan-init.sh -sSf | sh   # ~2 min
    sh bin/verify.sh

`lean/` has **no imports**. No Mathlib, no `lake`, no network after the
toolchain. If `verify.sh` exits 0, everything in `STATE.md` is true of the tree
in front of you. If it exits non-zero, something is wrong and it will say what.

## What the gate checks

1. **Positive control** — the corpus passes its own axiom census.
2. **Negative control** — every file in `probes/` is *rejected*. A probe that
   passes means the alarm is broken.
3. **Generated, not typed** — `STATE.md` regenerates byte-identically.
4. No stray `.lean` outside `lean/` and `probes/`.

Check 2 is the one that matters. A checker only ever run on files that pass has
no evidence behind it. Three separate holes in this checker were found by
planting something false and watching it fail to ring:

- a `sorry` inside a `def` that no theorem depended on
- an axiom outside the denylist — fixed by making it an **allowlist**
  (`propext`, `Classical.choice`, `Quot.sound`, nothing else)
- declarations the extractor never matched, and so never probed

`probes/axiom_probe.lean` proves `2 + 2 = 5` from a planted axiom. **`lean`
exits 0 on it, with no warning** — a planted axiom is not an error. That file is
the reason exit status is not a gate, and it is kept so the claim stays testable
instead of remembered.

## Layout

    bin/check.sh    axiom census: injected over every declaration, aborts if it
                    cannot extract, allowlist not denylist, plus an independent
                    gate on lean's own `uses 'sorry'` warning
    bin/report.sh   generates STATE.md from live runs
    bin/verify.sh   the four gates above
    lean/           the corpus, zero imports
    probes/         files that must fail
    STATE.md        generated — do not edit
